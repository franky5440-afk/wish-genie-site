# wish-genie-site

Static pages for the iPhone app **Wish Genie: Health Export** (許願精靈：健康匯出), served with GitHub Pages:
home page, user guide, support and privacy policy, in English and Traditional Chinese. Plain HTML and CSS, plus one small self-hosted script (`site.js`) for animations and the contents list; every page reads the same without it. No third-party requests, no analytics, no cookies.
